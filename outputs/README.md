# Elaborati generati

Rigenerare con `python -m src.generate` (tavole e registri) e `python -m src.render` (anteprime 3D).
L'elenco aggiornato dei file, con revisione e scala di stampa, è in `MANIFEST.md`.

- `A01`, `E01` — pianta arredi e punti utenza, A3 1:50.
- `F01`–`F04` — prospetti, A3 1:20.
- `AB01_abaco_arredi.md`, `Q01_quote_aperte.md`, `criticita.md`, `revisione_correzioni.md`.
- `render/R01_*.png` — anteprime 3D dal modello; non sono fonti metriche e non sostituiscono la vista approvata.

I file sono riproducibili da `config/geometry.json`. Non si tratta di disegni esecutivi: PRELIMINARE - NON PER CANTIERE.
